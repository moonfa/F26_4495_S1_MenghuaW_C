# Personal Investment Workbench v2

The project overview, a step-by-step demo and the short install steps are in the repository's top-level `README.md`. This file has the detail.

A local, single-user research tool that tracks an investment **thesis** per company over time (instead of regenerating one-off reports), keeps your holdings, position plans, trade reasons and journal in one place, and includes a **valuation lab** that shows what a price implies.

- Runs on your own computer. Your data stays in two local SQLite files. There is no login, so the server must only listen on `127.0.0.1`.
- Market data comes from Yahoo Finance through OpenBB. Optional AI text (thesis updates, translation) comes from Google Gemini. Without a key the app runs in **mock** mode and still works.
- Code computes, AI interprets. Holdings, plans, trade reasons, journal entries and decision notes are never sent to a model.

| Page | URL | What it is |
|---|---|---|
| Workbench | `http://127.0.0.1:8000/` | Overview, companies (Brief, Position & plan, Thesis, Valuation, Fundamentals, Timeline, Notes), Portfolio, Journal, Calendar, Guide |
| Valuation lab | `http://127.0.0.1:8000/valuation` | Compare tickers, single-company valuation (P/E, P/FCF, EV/EBITDA), Guide |
| API docs | `http://127.0.0.1:8000/docs` | Generated by FastAPI |

## What the app does

| Area | What you get | Model used? |
|---|---|---|
| **Companies** | One thesis per company: Brief, Position & plan, Thesis (assumptions with status and kill criteria), Valuation, Fundamentals (quarterly and annual statements), Timeline, Notes. Refresh makes a baseline, an update, or a free "no change" check. | Only for baseline and update text |
| **Portfolio** | Import holdings and trades from a Futu CSV; weights, plans with buy / target / stop prices and position sizes; trade reasons and outcomes by strategy. | No |
| **Journal and Calendar** | Portfolio-level diary with a code-built review checklist; month, week and list calendar of trades, reviews and revisit dates. | No |
| **Valuation lab** | Compare tickers, or open one company: one period table (reported years, TTM, analyst years, your years), exit at a fiscal year end, exit multiple, annual return, "what you must believe" grid, notice when analyst estimates change, a "read this first" block with exit-multiple lenses, saved snapshots (deletable). Linked to the company page: out-of-date flags, return at your Plan price, assumption-to-valuation-input links, a question saved to Notes. | No |
| **Chinese on demand** | Analysis text can be translated; the valuation lab has an English / 中文 switch for its explanations and Guide. | Translation only |
| **Security** | Local-only: Host and Origin checks, security headers, http(s)-only links, no secrets in the browser. | No |

## Setup after cloning

These steps are needed because the repository deliberately does **not** contain your environment, your API key or your data (`.gitignore` excludes `.env`, `*.db` and `.venv/`).

```bash
git clone https://github.com/moonfa/F26_4495_S1_MenghuaW_C.git
cd F26_4495_S1_MenghuaW_C/Implementation/workbench_v2     # the folder that contains app/ and requirements.txt

# 1. Create an isolated environment and install the packages (pip needs a few minutes the first time)
python3 -m venv .venv
source .venv/bin/activate        # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2. Create your settings file
cp .env.example .env             # Windows: copy .env.example .env
#    then open .env and edit it (see the next section)

# 3. Start the server
python -m uvicorn app.main:app --reload --reload-dir app
```

Open `http://127.0.0.1:8000/`. The first start takes longer: OpenBB builds its extension files once (the log shows "OpenBB initialized."). The databases `workbench.db` and `valuation.db` are created automatically in the project folder the first time they are needed.

Notes:

- Keep `openbb==4.7.2` as pinned in `requirements.txt`. Version 5 changed its interface and breaks the data adapter.
- `--reload-dir app` stops the reloader watching `.venv`, which otherwise restarts the server endlessly.
- Never start the server with `--host 0.0.0.0`. The app has no login. It refuses requests whose `Host` is not local (`ALLOWED_HOSTS` in `.env` can add names you trust).
- Stop the server with `Ctrl+C`. Start it again later with the last command only, after `source .venv/bin/activate`.

## Configure `.env`

`.env.example` lists the main settings. The ones you will normally touch:

| Setting | Default | Meaning |
|---|---|---|
| `AI_PROVIDER` | `mock` | `mock` writes placeholder analysis with no key. `gemini` calls Google Gemini. |
| `GEMINI_API_KEY` | empty | Your key from Google AI Studio. Required only when `AI_PROVIDER=gemini`. **Never commit this file.** |
| `AI_MODEL` | empty | A Gemini model id your key can use (for example one listed in AI Studio). Required for `gemini`. |
| `AI_MODEL_BASELINE` | empty | Optional stronger model tried first for first-time baselines only. |
| `AI_MODEL_FALLBACKS` | empty | Comma-separated models tried in order when `AI_MODEL` is out of quota. |
| `AI_THINKING_BUDGET` | `1024` | Tokens the model may spend thinking. `0` turns thinking off. Raise it if long answers get cut off. |
| `OPENBB_PROVIDER` | `yfinance` | Market data source. Free, no key. |
| `DATABASE_URL` | `sqlite:///./workbench.db` | Where the main database lives. |
| `ALLOWED_HOSTS` | empty | Extra host names allowed to reach the server. Leave empty for local use. |

If you accidentally commit a key, revoke it in Google AI Studio and create a new one; deleting the file afterwards is not enough because Git keeps history.

## Check that it works

```bash
./check.sh        # prints the folder and version the server on :8000 is really running
curl http://127.0.0.1:8000/api/v1/health
```

Then in the Workbench type a ticker (for example `MSFT`) into the **Add ticker** box and open it. With `AI_PROVIDER=mock` you get a deterministic placeholder thesis; with `gemini` you get a real baseline. In the valuation lab, enter two or three tickers on **Compare** (each import takes 10 to 20 seconds).

If a page looks old after an update, hard-refresh the browser (`Cmd+Shift+R` / `Ctrl+Shift+R`) and run `./check.sh` to confirm which folder the server is serving from. Duplicate folders such as `project 2` are the usual cause.

## Your data and what leaves your computer

- `workbench.db` holds companies, theses, notes, holdings, trades, plans and journal entries. `valuation.db` holds valuation records (never edited; you can delete one from the Saved snapshots list). Both are git-ignored. Back them up by copying the files while the server is stopped.
- To Yahoo Finance (through OpenBB): ticker symbols you analyse.
- To Gemini, only when `AI_PROVIDER=gemini`: public market data and the thesis state for the company being analysed, plus notes you tag as comment, source or question (labelled unverified). Never holdings, plans, trade reasons, journal entries or decision notes.
- Valuation numbers are computed by code. No model is called on the valuation page.

## What the valuation lab is, and is not

It answers two questions: what annual return does today's price imply under assumptions you can see, and which of several companies offers more on the same rules. Results are conditional arithmetic, not forecasts: there is no back-test, no prediction track record, no dividends in the price return, and Bear/Base/Bull are not probabilities. Analyst numbers are provider consensus with an unverified GAAP/adjusted basis. Open the **Guide** tab in the lab for the four layers it keeps apart: reported facts, analyst consensus, your assumptions, and calculated results.

## Troubleshooting

| Symptom | Likely cause and fix |
|---|---|
| `'App' object has no attribute 'equity'` | OpenBB 5 is installed. `pip install "openbb==4.7.2"`. |
| `signal only works in main thread` | Start the server with the command above; OpenBB is imported once at start-up on purpose. |
| `openbb_import_error` in the log | The install is incomplete. Re-run `pip install -r requirements.txt` inside the activated `.venv`. |
| "Frontend not built yet" | You are in the wrong folder. Run the server from the folder that contains `app/static/index.html`. |
| Analysis says output exceeded the maximum | Raise `AI_THINKING_BUDGET` or use a model with a larger output limit. The app retries once with a larger limit. |
| News list is empty for an ETF | Some tickers have no company news on Yahoo. The app tries several routes; an empty list is possible. |
| Server keeps restarting | You started it without `--reload-dir app`, so the reloader is watching `.venv`. |
